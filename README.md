# SAMAYA - Smart Timetable Generator

**SAMAYA** is an intelligent timetable generation system designed to simplify and automate the process of creating efficient, conflict-free academic schedules for educational institutions.

## 🚀 Features

- ✅ Automatic generation of class timetables
- ✅ Conflict-free scheduling for teachers and classrooms
- ✅ Customizable inputs: subjects, faculty, hours/week, classrooms
- ✅ User-friendly web interface
- ✅ Downloadable timetable output

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python (Flask)
- **Algorithm**: Custom logic for schedule generation
